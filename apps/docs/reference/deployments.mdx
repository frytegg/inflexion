<Note>
**Why a fresh redeploy on 2026-06-05?** The Stylus `FairValueOracle` carries a **set-once `init()`** that binds it to one `VolOracle`. The prior FVO had already been `init()`-bound to the old VolOracle, so reusing it would have orphaned the new vol's `σ_ref`. The clean fix was to deploy a fresh FVO and `init()` it to the fresh VolOracle — which in turn meant a full-fresh stack so every contract points at the right neighbour. The same redeploy lowered `optimizer_runs` to 1500 and extracted the public libraries as delegatecall code, bringing `InflexionCore` to **23,934 B — under the 24,576 B EIP-170 limit**.
</Note>

### Core protocol (Solidity stack)

These are the on-chain contracts under `deployment.core` in the registry.

| Contract | Role |
| --- | --- |
| **InflexionCore** | State machine. `createSwapPathA` / `createSwap` (Path B) / `createSwapRouted`; enforces I1–I10; CEI settlement; the EIP-712 `verifyingContract` for signed quotes. |
| **OracleManager** | Chainlink-anchored entry/settlement price + sequencer + staleness + lone-spike + advisory Uniswap-TWAP. `getPrice` (entry) / `getSettlementPrice` (settle). Reverts on stale feed / sequencer down. |
| **VolOracle** | `σ_ref = max(σ_short, σ_long, floor)` — a poke-based, time-aware EWMA of Chainlink-tick log-returns. Never raw realized σ. |
| **ILMath** | **Production** settle-path math (Solidity). `computeMaxIL` / `computeIL` / `getAmountsForLiquidity` — pure Q64.96 fixed point. |
| **ILVault** | ERC-721 custody of the LP's Uniswap v3 position NFT during an active swap; `claimFees` passthrough to the registered LP. |
| **UnderwriterVault** | Per-MM collateral home for **Path B** (`deposited` / `locked` / `available`). `lockCollateral` / `releaseAndDistribute` (onlyCore). |
| **ConvexityVault** | The cvAMM pooled underwriter for **Path A**. USDC ERC-4626, **dual-tranche SENIOR/JUNIOR from launch**. One per pair, backs all 9 markets with fungible capital. |
| **Treasury** | Protocol treasury — takes the 1% premium cut. Same EOA as the deployer on this testnet. |

### The Stylus FairValueOracle (the production fair-value pricer)

| Field | Value |
| --- | --- |
| **Address** | `0x98a6aa75108b70fc0794bc3b87efe0ae99d5d52c` |
| **Activation tx** | `0x8fc48dc62c0a99ad636301a008fba5bbd02e84e85d6abb373aa2767572d55a6c` |
| **Runtime size** | `21702` bytes |

This is **production** — the exact closed-form `fairRate` Φ-sum that yields `FairPremium = fairRate · MaxIL`, machine-precise to ≤ 1e-12 (≈ 6.7×10⁻¹⁵). It exposes `fairRate` / `fairRateFromPrices` / `fairPremium` / `volOracle`.

<Warning>
**The Φ-sum is NEVER reimplemented off-chain.** Stylus bans WASM floating point at activation, so every transcendental (erf/Φ, exp, ln, sqrt) is **integer fixed point** — 1e24 internal, WAD 1e18 ABI. The Solidity `FairValueOracle` reference implementation exists **only** as a revm-testable CI cross-check (Φ via Abramowitz–Stegun, ~1e-7), **not** a second production oracle. The SDK reads the on-chain FairPremium and never approximates it — see [Fair value](/concepts/fair-value).
</Warning>

### Deployed Solidity libraries (delegatecall-only)

Auto-deployed and linked during the deploy broadcast. Extracting these as public-library delegatecall code is part of what brought `InflexionCore` back under the EIP-170 limit.

| Library | Address | Role |
| --- | --- | --- |
| **TickMath** | `0xbf02bbc82e0fb1a4b9828bb90fc9dd9e97578965` | tick → sqrtPriceX96 (pure). |
| **CvammPricing** | `0x4a053d29a55a64172140f9ebbc27c321c0ba2b53` | The Path-A load stack — `totalLoadWad` / `loadComponents` (base/util/disp/total). |
| **SwapMath** | `0xf7be9745b6768d06a18c386c6db5c8cb065ba314` | Entry token amounts + oracle→sqrtP conversion (pure). |
| **QuoteVerification** | `0x74819eed322f3e1a2dc10bb0d3cae50078d90807` | EIP-712 quote hashing / signature check. |

<Warning>
**Limitation → Why → Mitigation.** A direct `eth_call` to any of these deployed libraries **reverts**. **Why:** Solidity guards deployed library functions to be **delegatecall-only**, so they cannot be called as standalone contracts. **Mitigation:** the SDK never reads them directly — it keeps a **parity-locked TypeScript mirror** of the *load* math instead. The `fairRate` Φ-sum is the exception: it is always read from the on-chain Stylus oracle, never mirrored. See [marketId parity](/integrate/marketid-parity) and [the cvAMM port](/sdk/cvamm-port).
</Warning>

## The live create→settle lifecycle (2026-06-05)

A **live, no-time-warp** create→settle ran on a short 300s fee-500 market `0xb8bbd684f213d5833886ade7b531a6949d85522249881a2b5d46a5cc76e439c2`, settled at the Chainlink round bracketing each expiry. All amounts are in USD (`dUSDC`, 6 dec). The fresh demo MM `0xe632B215120dD43A719458487bA3e03638fec953` deposited 5,000 `dUSDC` into `UnderwriterVault`, and its **own** collateral paid the Path-B settlement.

<Note>
The 300s lifecycle market is a **separate, extra** market used only for this live create→settle proof. It is **not** one of the 9 production markets.
</Note>

<Tabs>
  <Tab title="Path A — cvAMM pool (swapId 1)">
    LP tokenId `3220`, settled from the `ConvexityVault`:

    | Field | Value | Meaning |
    | --- | --- | --- |
    | V0 | `270,531.28` | position value (numéraire) at entry |
    | MaxIL | `1,669.24` | collateral locked = the cap |
    | premium | `9.70` | what the LP paid |
    | premium % of MaxIL | `0.58%` | the convexity premium is a tiny fraction of MaxIL |
    | settled realized IL | `148.64` | actual IL at expiry |
    | settled payout | `148.64` | paid to the LP, from the ConvexityVault (below the cap, so no truncation) |

    With `MaxIL ≈ 0.62%` of V0 and a premium of just `0.58%` of MaxIL, the LP paid **\$9.70 to cap \$1,669.24 of in-range IL** — the convexity-hedge signature. See the [worked example](/math/worked-example).
  </Tab>
  <Tab title="Path B — routed to MM (swapId 2)">
    LP tokenId `3221`, settled from the **MM's own** `UnderwriterVault` collateral:

    | Field | Value | Meaning |
    | --- | --- | --- |
    | premium A (cvAMM) | `13.80` | the pool's price |
    | premium B (MM) | `8.93` | the MM's price |
    | chosen path | **B (MM)** | `createSwapRouted` picked the MM because it **strictly** beat the pool |
    | MM loadBps | `1000` (10%) | MM's load over FairPremium |
    | MaxIL | `3,215.65` | MM collateral locked |
    | settled realized IL | `245.66` | |
    | settled payout | `245.66` | paid from the **MM's OWN** collateral |

    This is the on-chain proof of the two rails: Path A is always-on and signature-free; Path B wins the route **only** when it genuinely undercuts the capped pool price, and the MM's own collateral settles it. See [routing](/protocol/routing) and [the two rails](/concepts/two-rails).
  </Tab>
</Tabs>

The math at settlement is **identical regardless of which rail opened the swap** — `payout = min(realized_IL, MaxIL)`, paid from the counterparty's own collateral, with the LP receiving `payout` and the counterparty keeping the residual `collateral − payout`. The lifecycle above demonstrates the trust model end to end: protocol funds are never at stake.
